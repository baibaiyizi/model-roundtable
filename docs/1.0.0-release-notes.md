# 模型圆桌 1.0.0

首次公开发布的中文 Windows x64 多模型讨论与执行桌面应用。

## 可以做什么

- 接入自己的模型服务，使用圆桌、自由群聊或正式辩论；保存项目、多聊天、资料与可追溯引用。
- 将讨论方案交给 OpenCode、Codex 或 Claude Code 后台执行，查看真实文件改动，并由多个模型审阅；最多两轮自动修复与复核。
- 使用应用统一搜索、长期知识库、MCP 与 Skill，以及每个服务独立的系统/直连/订阅节点线路。
- 通过同版本 VS Code 伴随扩展发送选区和文件，首次确认一次后跨项目接收；发送内容不会自动调用模型。

## 本次公开发布整理

- 使用新的独立 Git 历史和统一 1.0.0 版本；数据目录和应用标识保持稳定。
- 按产品参考、实际依赖、独立程序与可选扩展逐项记录来源、许可证和分发材料。
- 官方 Claude Code 提供订阅、Console、自有 API Key 和原版 CLI 入口，保留按服务认证与线路隔离。
- 补齐源码归档、Windows 构建、伴随扩展打包、隐私与许可证检查。
- 提供中文发布文案、真实界面宣传图及横竖字幕演示视频。

## 下载与使用

安装 `Model-Roundtable-1.0.0-win-x64.exe`。VS Code 用户另外安装 `model-roundtable-companion-1.0.0.vsix`，或在应用设置中安装伴随扩展。

软件原创源码开源免费，模型及搜索、Embedding、视觉、转录等服务费用由用户承担。需要的独立组件首次使用时下载；不随安装包附赠模型账号、模型额度或代理订阅。当前未配置商业代码签名。

完整对应源码包含 FFmpeg、Mihomo 的许可、匹配源码与构建材料，请下载本 Release 的 `Model-Roundtable-1.0.0-source.zip`，不要仅用 GitHub 自动生成的源码 ZIP 代替。

本轮实际验收与限制见同版本 `validation.json` 和源码 `VALIDATION.md`；使用前可对照 `SHA256SUMS.txt` 校验下载文件。
