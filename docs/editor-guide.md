# VS Code 资料协同

1.0.0 将编辑器连接与项目分开：首次确认一次，随后直接发送到圆桌统一收件箱。无需配对码、绑定目录或在 VS Code 选择讨论。

## 安装和首次连接

1. 安装 VS Code 1.138 或更新版本；在圆桌「模型与设置 → 编辑器协同」点击「安装／更新伴随扩展」。也可从 VSIX 安装 `model-roundtable-companion-1.0.0.vsix`，必要时重新加载窗口。
2. 圆桌保持运行。在 VS Code 打开本机文件或未命名文本，选中文字，右键「模型圆桌：发送选中文本」。
3. 首次发送会在圆桌出现连接请求，点击「允许连接」。请求五分钟有效，可拒绝或取消。没有手动配对码。
4. 成功后回圆桌打开「VS Code 资料」，选择接收用途并确认。之后同一 VS Code 用户配置下的其它本机窗口复用连接，不要求两边有相同项目，甚至不必打开文件夹。

检测到 VS Code 不代表扩展已安装。已有用户主动关闭的资料连接保持关闭，可在编辑器协同设置重新开启；新安装默认允许本机连接请求。

## 发送文字和文件

- 文字取自当前编辑缓冲区，保留来源、行号、时间、哈希和未保存标记。未命名文本无需先保存，也不会伪造磁盘路径。
- 右键即发送，不在 VS Code 连续弹出目标选择。收件箱默认新建独立讨论，也可搜索并选择任意项目的新讨论、可继续输入的已有讨论或新执行草稿。
- 新执行草稿必须选择实际工作项目；资料来源可以位于其它目录。收到或追加资料不会启动执行、发送模型请求或打断发言。
- 已有草稿、模型和成员选择保留；追加后的完整正文最多 20,000 字符，超限时保留原草稿和待处理记录，不截断资料。
- PDF、DOCX、Excel、CSV、PPTX 在资源管理器右键「模型圆桌：导入资料到知识库」，或从命令面板选择文件。无需圆桌项目，回圆桌核对完整路径及目标集合后才保存原件、解析和调用 Embedding/视觉能力。
- 原件已删除、路径失效或链接实际位置变化会明确报错，需重新选择发送。普通文字的文件定位以资料记录为准，与接收项目无关；未命名文本没有磁盘定位入口。

侧栏「VS Code 资料」仅在有待接收或导入记录时显示，已追加和已移除的记录不计入。清理记录不删除已导入的知识库资料。

## 送回 VS Code

圆桌讨论消息、总结及执行结果的「发送到 VS Code」创建新的未保存 Markdown 文档并打开原生预览，不覆盖文件。一个在线窗口直接接收，多个窗口需明确选择；内容不会广播。项目及文件的「在 VS Code 打开」继续使用 VS Code 官方 CLI。

可以自行使用 [Draw.io Integration](https://github.com/hediet/vscode-drawio) 或 [vscode-pdf](https://github.com/tomoki1207/vscode-pdfviewer)。第三方插件使用自己的账号、权限和网络，圆桌不自动安装，也不读取其 Webview。打开文件不等于已经解析文件；第三方 PDF / Draw.io 插件不属于本版保证范围。

## 排错与撤销

| 现象 | 处理 |
| --- | --- |
| 没有右键菜单 | 确认已安装同版本扩展并重新加载窗口；使用可信的 Windows 本机文件或未命名文本，发送选区前先选中文字 |
| 应用未启动或连接关闭 | 启动圆桌，并在编辑器协同设置开启资料连接 |
| 申请被拒绝、取消或过期 | 再次右键发送，或在命令面板运行「模型圆桌：重新连接应用」；不会自行反复申请 |
| 提示协议版本不匹配 | 同时更新圆桌和伴随扩展，不混用旧版本 |
| 已连接但没有接收窗口 | 在 VS Code 查看连接状态或重新连接；关闭的窗口不会继续接收 |
| 草稿过长或目标被删除 | 在收件箱重新选择目标，缩小选区或改用知识库；原内容不覆盖 |
| 来源文件失效 | 重新选择文件发送，不能用接收项目中的同名文件替代 |
| 发送中断 | 使用「模型圆桌：重试未确认传输」手动重试同一快照，或移除记录 |

「关闭资料连接」停止服务但保留资料；「撤销连接」使对应令牌失效。VS Code 也可运行「模型圆桌：撤销连接」。连接只访问 `127.0.0.1`，不经过代理；令牌在应用加密存储和 VS Code SecretStorage 中保存。资料和待重试快照存于本机，不宣称资料另行加密。

支持可信的 Windows 本机 VS Code；Remote/SSH、WSL、浏览器版及虚拟工作区不接入。应用固定沿用 `%APPDATA%/model-roundtable/v2`，保留已有配对凭据与资料；旧资料保留原始来源引用，来源项目不存在时保留记录并提示重新发送。具体检查见 [验收记录](../VALIDATION.md)。
