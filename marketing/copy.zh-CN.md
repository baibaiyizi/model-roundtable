## 中版

手里接了好几个模型，却总在不同窗口间复制粘贴——所以我做了「模型圆桌」。

它是一个中文 Windows 桌面应用，可以把不同服务的模型放进同一场讨论：先各自提出观点，再互相质疑，最后整理共识、分歧和待验证的问题。你也可以选择自由群聊或正式辩论，主持人按需加入。

讨论不止停在答案上。把方案交给执行者，它能修改项目文件、运行命令；之后由多个模型审阅，有问题最多自动修复两轮。实际改动、差异和未解决的问题都会留下记录。

另外还支持长期知识库、联网检索、项目下多个聊天、每个服务独立网络设置，以及 VS Code 右键发送资料。

今天把 1.0.0 开源了。应用免费，模型 / 搜索 / 资料处理仍使用你自己的服务；必要资料会发送给所选模型或服务。有些组件首次使用时需要下载。多模型也会犯错，重要结果请自行核对。

下载与源码：https://github.com/baibaiyizi/model-roundtable
欢迎试用、提 Issue，也欢迎一起改进。

## 长版

我把几个模型接进了同一张「圆桌」，现在把这个 Windows 应用开源了。

起因很简单：我有自部署模型，也用不同公司的模型。遇到一个问题，经常要分别问一遍，再手动把答案搬来搬去。后来我想，能不能让它们直接读同一份资料、互相讨论，并把最后的方案做出来？

于是有了「模型圆桌 1.0.0」。

**先讨论。** 圆桌模式会先独立回答，再交叉评议，整理共识、分歧和证据不足之处；自由群聊可以点名、插话、暂停；正式辩论按正反双方和裁判推进。圆桌与群聊的主持人可选，模型和讨论角色分别设置。

**再动手。** 讨论中的方案可以交给执行者。它使用成熟 Agent 后台，直接修改选定项目里的真实文件、运行命令，保存操作与差异。多个审阅者随后检查结果；需要修改时，最多自动修复与复核两轮，仍有问题就交回给你。应用不会把「多数模型同意」当成正确率。

**资料和项目留在一起。** 一个项目可以保存多个讨论与执行记录，知识库可以跨讨论复用，引用保留实际用到的材料快照。也能从 VS Code 右键发送选区、未保存文本和资料文件，收到后先进入收件箱，由你决定去哪里；不会自动启动模型。

**不同服务，各走各的线路。** 每个模型服务可以选择跟随系统、直连或兼容订阅中的固定节点，不必在整场讨论里反复手动切换。联网检索也不要求先安装搜索 MCP；MCP 和 Skill 则作为可选扩展。

应用采用 Electron、React 与 TypeScript，本地 SQLite 保存记录，LanceDB 管理知识库索引；成熟执行后台通过受限工具通道工作。配置、历史与原件保存在本机，必要资料会发送给你选择的模型或服务。

这还是一个值得继续打磨的个人桌面工具。目前面向 Windows 10/11 x64；原创代码 MIT，复用组件保留各自许可与致谢。应用免费，模型、搜索和资料处理费用由所选服务收取。执行会真实修改文件、以当前用户身份运行命令，请检查任务范围与结果。

发布视频使用隔离的演示数据与受控响应，展示真实界面和真实文件操作；等待经过剪辑，不是模型速度或能力对比。

GitHub / 安装包 / 使用说明：
https://github.com/baibaiyizi/model-roundtable

如果你也想把手里的模型一起用起来，欢迎试试，遇到问题提 Issue。项目里逐项记录了参考项目和第三方组件，感谢这些开源工作。

## 常见问题

**免费吗？** 应用原创代码 MIT 开源、可免费使用。模型、搜索和资料处理使用你自己的服务，可能产生费用。

**哪些模型能接？** 支持 OpenAI 兼容接口、自建网关和应用提供的官方 Agent 账号接入。各模型能力和订阅支持以实际服务为准，并非任意网站会员都能直接导入。

**只是把多个回答并排放着？** 圆桌包含独立首轮和交叉评议；此外有自由群聊、正式辩论，以及讨论交给执行者、多模型审阅的流程。

**真的会修改文件吗？** 会。执行在你选择的项目目录内进行，保存操作记录和差异。命令以当前 Windows 用户身份运行，项目目录不是系统沙箱；请核对任务范围和结果。

**需要先装搜索 MCP 吗？** 不需要。应用已有免 Key 浏览器搜索；Tavily、SearXNG 或搜索 MCP 可作为可选来源。搜索可能受网络、验证码或服务可用性影响。

**能直接装所有 VS Code 插件吗？** 不能。第三方插件在你的 VS Code 里运行，伴随扩展负责双向发送资料；圆桌不托管全部 VS Code 插件。

**资料是否只在本机？** 配置、历史和原件保存在本机；调用模型、Embedding、视觉、转录、搜索或扩展时，所需内容会发往你选择的服务。它不是全离线产品。

**联网能解决所有访问问题吗？** 每个服务可选独立线路，并支持 Clash/Mihomo 兼容订阅。不提供代理订阅，不保证任意 VPN 链接可用；远程网关到上游的线路仍由网关负责。

**截图里 demo-* 是什么？** 为拍摄准备的本机受控演示响应，不冒充任何公司的真实模型答案；执行展示的文件写入与差异来自真实工具流程。

**准确率会更高吗？** 不保证。多模型可以帮助比较观点和发现分歧，也可能共同犯错；重要结论仍需结合来源人工核验。
